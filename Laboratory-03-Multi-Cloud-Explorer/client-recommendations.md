# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is a good choice for a startup because it provides many cloud services that can scale as the company grows. The company can start with a small amount of resources and increase them when more users join the application. AWS also provides many services that can help reduce the need to manage physical servers.

**Three useful services:**

* Amazon EC2 – for running the mobile application's backend
* Amazon S3 – for storing images and files
* AWS Lambda – for running code without managing servers

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration and user management easier. The university can move selected services to Azure while continuing to use familiar Microsoft tools.

**Three useful services:**

* Azure Virtual Machines – for running Windows Server workloads
* Microsoft Entra ID – for identity and access management
* Azure Storage – for storing files and backups

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud is a strong choice for an AI and Machine Learning research company. It provides powerful computing resources and tools designed for AI and data workloads. Google Cloud also offers services that make it easier to develop, train, and deploy machine learning applications.

**Three useful services:**

* Google Compute Engine – for high-performance computing
* Google Kubernetes Engine (GKE) – for running containerized AI applications
* Vertex AI – for developing and deploying AI and machine learning models

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is a suitable choice for a global e-commerce company because it has infrastructure in many locations around the world. AWS services can automatically scale resources when customer traffic increases and help keep applications available. This makes AWS suitable for an online store that needs reliable performance for customers in different countries.

**Three useful services:**

* Amazon EC2 – for running e-commerce applications
* Amazon S3 – for storing product images and files
* Elastic Load Balancing – for distributing traffic across servers



# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement    | Recommended Platform | Justification                                                                                                                                                                                                                                                                    |
| ----------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Startup Company         | AWS                  | AWS provides a wide range of scalable services and flexible pricing options that can help startups control costs as they grow. Services such as Amazon EC2, Amazon S3, and AWS Lambda can support application development and deployment.                                        |
| Enterprise Organization | AWS                  | AWS offers a broad selection of enterprise-grade services, strong security features, and global infrastructure. Organizations can use services such as Amazon EC2, Amazon RDS, and Amazon VPC to build reliable and scalable systems.                                            |
| Microsoft Environment   | Azure                | Azure is the best choice for organizations that already use Microsoft technologies. It integrates well with Windows Server, Microsoft 365, Active Directory, and other Microsoft products.                                                                                       |
| AI / Machine Learning   | GCP                  | GCP is a strong choice for AI and machine learning because of its AI services and machine learning tools. Services such as Vertex AI, BigQuery, and Google Cloud Storage can support data analysis and machine learning workloads.                                               |
| Kubernetes Deployment   | GCP                  | GCP provides Google Kubernetes Engine (GKE), a managed Kubernetes service designed for deploying and managing containerized applications. It provides automation, scalability, and integration with other Google Cloud services.                                                 |
| Global Web Application  | AWS                  | AWS is suitable for global web applications because it has a large worldwide infrastructure and many services for delivering applications to users in different regions. Amazon EC2, Amazon CloudFront, and Amazon Route 53 can help provide scalable and reliable web delivery. |
