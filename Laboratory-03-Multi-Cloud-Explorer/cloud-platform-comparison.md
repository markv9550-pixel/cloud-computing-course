## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of cloud services among the three major providers. AWS currently provides over 200 cloud services covering computing, storage, databases, networking, security, analytics, and other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies. It works closely with products and services such as Windows Server, Microsoft 365, Active Directory, and GitHub.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes. Google developed Kubernetes, and Google Cloud provides Google Kubernetes Engine (GKE) along with many AI and machine learning services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose **AWS** because it offers many different cloud services and provides a wide range of tools for learning and building applications. It is also widely used by businesses, making it useful for developing cloud computing skills.
